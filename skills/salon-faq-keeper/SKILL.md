# 常見問題回覆庫：會過期的答案要有日期

把「打 2 分鐘字」變成「點 2 秒鈕」。可是價格一調、營業時間一改，舊答案還在回，客人就會拿截圖來問。這支技能讓每一題都知道自己什麼時候該改。

## 一、第一次建庫：先問她
1. 服務項目與價格（貼價目表）
2. 營業時間、地址、停車、付款方式
3. 預約、改期、遲到的規則
4. 客人最常問的 10 個問題（想不到就用 LINE 聊天紀錄裡最常出現的）

## 二、每一題的格式
```
題號：Q07
題目：凝膠卸甲要多少？
客人可能的問法：①卸甲另外算嗎 ②卸別家的做的要加錢嗎 ③只卸不做多少
標準答案：（80 字內，價格時間地址只用她給的，沒有的寫【待補】）
依據：價目表 2026-09 版
最後更新：2026-09-26
有效到：下次調價前／2026-12-31（她定）
轉真人：否
```

## 三、一定轉真人的題目（不寫答案）
過敏、紅腫刺痛、做完不舒服、懷孕或用藥、能不能治療、客訴、退費解約、要查詢或刪除自己的資料。
這些題的答案一律是：「這個問題我想親自回覆妳，請留下方便聯絡的時間。」

## 四、她說「我改價了／改時間了」的時候
1. 請她說清楚改了什麼、哪天生效
2. 列出所有提到舊價格、舊時間的題號，舊句和新句並排
3. 提醒她同一個資訊還可能出現在：LINE 預設訊息、AI 聊天機器人問答、IG 簡介、Google 商家檔案、店內價目表
4. 生效日前後都有客人問的話，答案寫清楚「幾月幾日起」

## 五、輸出成 LINE 能用的格式
她要放進 LINE 官方帳號的 AI 聊天機器人（β）時，改成「一問一答」：每題三種問法＋一個標準答案（80 字內），轉真人題照第三節。
提醒她（2026-09 查核）：AI 聊天機器人是「聊天進階方案」的功能，要付費；關鍵字自動回應免費但客人換個說法就接不到。以 LINE 官方當下公告為準。

## 客人個資
回覆庫是寫給所有客人看的，不放任何客人的姓名、電話、消費紀錄。從聊天紀錄整理問題時，先把客人資料刪掉再貼給 AI。

## 界線
AI 只寫草稿，上線前她要逐題看過；不自動發送、不自動上線。
