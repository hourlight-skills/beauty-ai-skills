# 客人偏好卡與服務小抄

客人會回來，常常是因為「這家店記得我」。記得她不喝薑茶、記得她喜歡安靜、記得她上次說要去日本。
記憶可以交給系統，溫度留給人。**但只記服務需要的，記越多越危險。**

## 一、偏好卡欄位（建議用 Notion 或試算表，存在她自己的帳號裡）
| 欄位 | 例子 |
|---|---|
| 客編 | A017 |
| 茶飲 | 洋甘菊，不喝薑茶 |
| 香氣 | 喜歡柑橘，避開薰衣草 |
| 力道 | 中等 |
| 聊天偏好 | 想安靜／可以聊／看當天（**讓客人自己選**，不照性別或年齡猜） |
| 上次聊到的事 | 下個月要去日本玩（只記客人主動說、下次接得上的一句） |
| 要避開的話題 | 不想聊工作 |
| 上次來的日期與項目 | 2026-09-10 臉部保養 |
| 服務上要注意的 | 客人自己說過的過敏或不舒服（**寫客人原話**；這一欄只留在店裡，不交給 AI） |

**不記**：生日、身分證、住址、家人與感情的細節、身高體重、宗教、自己猜的個性或健康狀況。
姓名、電話跟這張卡分開放，客編對照表只有她自己看得到。

## 二、每次服務後 1 分鐘更新
請她講或打幾句今天的狀況，AI 只整理成茶飲、香氣、力道、聊天偏好、上次聊到的事、要避開的話題；她沒說的欄位保持空白，**不自己補**。她講到過敏、身體不舒服、家人感情的事，AI 不整理進卡片，提醒她自己手寫在店裡的紀錄。

## 三、預約前的服務小抄
她貼上客編那一列（不要貼姓名電話，也先刪掉「服務上要注意的」那一格），AI 產生：
```
【A017 服務小抄】
進門：一句歡迎話＋接上次的話題（例：「上次說要去日本，玩得開心嗎？」）
茶飲：
香氣：
力道：
今天要注意：（空著，印出來後她對照店裡的紀錄自己補）
結束時：一句收尾話；她主動問產品才介紹
```
提醒她：服務剛結束、客人還在放鬆的時候不要推銷，等她自己問。

## 客人個資
- 偏好卡用客編；要給 AI 整理時，只貼那一列、不貼姓名電話 email 生日
- 過敏、不舒服屬於健康資料，不交給 AI，只留在店裡的紀錄
- 客人要求刪除自己的資料時，偏好卡和對照表一起刪
- 有裝 `salon-ai-privacy-check` 技能的話，第一次建表前先跑一次檢查

## 界線
偏好卡是服務筆記，不是病歷，也不做健康判斷。客人身體有狀況，請她問醫師。
