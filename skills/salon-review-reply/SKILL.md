# 負評回覆

收到負評的第一個反應通常是「這客人也太誇張了吧」。這時候最適合把 AI 叫出來：它不會生氣，可以幫妳在情緒上頭的時候，寫出冷靜的第一版。
這則回覆寫給兩個人看：留評論的客人，還有之後看到這則評論的每一位準客人。

## 先問使用者
1. 評論原文（貼上之前，先把客人的名字、帳號、電話、email、生日換成「客人A」這類代號；照片、截圖也先遮掉認得出是誰的地方）
2. 實際發生了什麼（她的版本，含日期、服務項目）
3. 已經做了什麼補救、打算提供什麼（沒有就寫沒有）
4. 發在哪個平台

## 先判斷：這則能公開回嗎？
下列情況先**不要**寫公開回覆的細節，改成一句「已收到，會親自聯繫妳」，其餘私下處理，並提醒使用者：
- 提到過敏、紅腫、刺痛、身體不適：服務中發現客人有異樣，要立即中止、協助就醫；把處理過程記下來
- 要求退費、解約：先算清楚（有裝 `salon-receipt-bookkeeping` 技能就用它的預收台帳；沒裝就請使用者列出客人買了什麼、用了幾次、付了多少），再私下談
- 牽涉個資（病史、電話、照片）
- 看起來可能要走法律程序

## 五段式回覆
1. 謝謝對方說出來（就算是負評）
2. 承認讓她不舒服的地方，不找藉口
3. 說明已經做了或會做的改善（只寫真的會做的）
4. 補救方案（有才寫，寫使用者給的，不自己加）
5. 對品質的承諾，歡迎她再給一次機會

語氣：專業、有溫度、不卑不亢。不過度道歉，也不辯解。150 字內。

## 這幾句一句都不寫
- 「那天很忙」「不是故意的」這類辯解
- 「您可能誤會了」（暗示客人錯）
- 「我們公司規定」
- 公開揭露客人的消費紀錄、身體狀況、個資
- 客人的真實姓名、帳號、電話（就算使用者不小心貼進來，回覆裡也一律不寫）
- 答應沒跟老闆確認過的退款或賠償

## 交出去的格式
```
【建議回覆】（150 字內）
【另外兩個版本】A 更溫柔　B 更簡短
【回覆前確認】□ 補救內容老闆同意了　□ 沒有揭露客人任何個資　□ 需要私下聯絡的已另外處理
```
