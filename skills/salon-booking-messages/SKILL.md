# 預約訊息與空檔通知

台灣的客人多半用 LINE 約時間。寫之前先讓她知道哪些訊息會花錢：
- **不扣則數**：一對一聊天、關鍵字自動回應、加好友歡迎訊息（她手動回預約，一則都不扣）
- **會扣則數**：群發、分眾、API 推播，照「收到的好友人數」算（好友 200 人群發一次，輕用量方案當月的免費額度就用完）
- 方案與價格（2026-09 查核）：輕用量 0 元每月 200 則；中用量、高用量 2026-11-01 起調價。**以 LINE 官方帳號當下公告為準**：https://tw.linebiz.com/service/account-solutions/line-official-account/

## 先問使用者
1. 店名、服務項目、地址、停車方式
2. 她的預約規則：改期要提前幾小時、遲到多久可能要縮短或改期
3. 要寫哪幾則（或全部）

## 一套六則（每則 80 字內，像熟客聊天：親切、不說教、不恐嚇）
1. 前一天提醒（日期、時間、地址、改期方式）
2. 當天早上提醒
3. 客人說要改期（留兩個空格讓她填可選時段）
4. 客人臨時取消
5. 客人沒來也沒通知，隔天的關心訊息
6. 同一位客人第二次沒通知就沒來，溫和說明預約規則

**不寫**扣堂數、沒收費用、過期作廢。這類店規有法規限制（例如做臉、美甲這類適用的美容定型化契約，不准約定「違約就拋棄已付費用」「過期就不能再接受服務」；美髮儲值、瘦身課程另有各自的規定），要寫進店規前先問縣市消保官或律師。

## 空檔通知（三個版本各 60 字內）
- A 給半年內來過的老客人　B 給超過 90 天沒來的　C 給還沒來過的新好友
- 每則最後加一句：「不想收到這類通知，回我『不用了』就好。」（個資法第 20 條：客人拒絕行銷要立刻停止，第一次行銷就要提供拒絕方式）
- 不用「最後名額」「錯過不再」，不寫效果承諾
- 提醒她：這種是群發，會扣則數

## 預約表分析（她上傳匯出的表格）
**上傳前先把姓名、電話、email、生日換成客編**（例：C023）；就算不小心貼進來，產出裡也一律不寫。欄位：客編、日期時間、服務項目、狀態（完成／取消／爽約）、金額。
請分析：
1. 一週裡最滿、最空的時段
2. 爽約率、取消率（附算式）
3. 每位客人平均幾天回來一次；列出超過自己平常週期 1.5 倍還沒回來的客編
4. 哪些服務最常被一起預約
最後給三個下個月可以試的做法，**每個都寫出是根據哪一個數字**。

## 發出前一定要人看過
- 日期、時間、地址、價格逐字對過
- 客人說過不想收推播的，從名單拿掉
- 線上預約表單要先告知客人（個資法第 8 條列的事項）：
  1. 店名（誰在蒐集）
  2. 蒐集目的
  3. 蒐集哪些資料
  4. 資料會用多久、在哪裡用、給誰用、怎麼用
  5. 客人可以查詢、閱覽、要複本、補充更正、要求停止蒐集、停止處理、停止利用或刪除，以及要找誰、怎麼申請
  6. 如果某些欄位可以不填，不填會有什麼影響（例：沒留電話就沒辦法傳提醒）
  範本裡用【店名】【聯絡方式】這類空格，不放任何真實客人資料。
