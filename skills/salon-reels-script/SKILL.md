# 美業短影音腳本

短影音開頭幾秒沒抓住人，觀眾就滑走了。所以腳本的第一句永遠放最有畫面、最讓人想知道下一句的那句。
「洗完臉總覺得緊繃？先看看這三個小習慣」比「今天來教大家正確的洗臉方式」好太多。
好的開場靠畫面和好奇心，不靠編數字嚇人：「讓妳老十歲」這種沒有根據的效果數字不要寫。

## 先問使用者
1. 主題（例：換季保濕、凝膠甲怎麼卸才不傷甲）
2. 想讓觀眾看完做什麼（學到一件事／留言／預約）
3. 長度：30、45 還是 60 秒
4. 露不露臉（不露臉就拍手部、工具、產品特寫）
5. 手邊有什麼可以拍的畫面（作品、工作台、前後對比）

## 腳本結構
| 段 | 時間 | 內容 |
|---|---|---|
| Hook | 0–3 秒 | 一句讓人停下來的話＋一個特寫畫面 |
| 重點 1–3 | 中間 | 一個重點配一個畫面，字幕短到一眼讀完 |
| CTA | 最後 5–10 秒 | 引導留言、收藏或預約，一次只要一個動作 |

## 交出去的格式
```
【片名】
【Hook（0–3 秒）】畫面：＿＿　字幕／旁白：＿＿
【重點 1（x–y 秒）】畫面：＿＿　字幕：＿＿
【重點 2】……
【重點 3】……
【CTA】畫面：＿＿　字幕：＿＿
【建議音樂風格】＿＿
【拍攝清單】要先拍好的 5 個鏡頭
【發布文案】60 字內＋5 個 Hashtag
```
再附 3 個不同的 Hook 讓她挑。

## 一定要守的
- 前後對比、成果影片：只用她真的做過、客人同意公開的作品；不要修到失真。
- 不說醫療效果、不承諾「幾次見效」、不編效果數字。寫完有裝 `cosmetic-ad-wording-check` 技能就再掃一次；沒裝就自己檢查有沒有：治療、根治、消炎、淡斑、生髮、醫美級、保證、一定、幾天見效。
- 音樂：IG／FB 內建音樂庫的歌，很多只限個人、非商業使用。店家宣傳影片，尤其要投廣告的，用 Meta 的 Sound Collection（標明可商用的曲庫）或自己買授權的音樂；每個平台規定不同，同一支影片要搬到別的平台前再確認一次。
- 畫面裡有客人的臉、手機畫面（LINE 對話、預約單），拍之前先取得同意、該打碼的打碼。客人的名字、電話、email、生日一律不放進字幕、旁白或發布文案。
