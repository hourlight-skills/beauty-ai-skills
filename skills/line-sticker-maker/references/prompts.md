# LINE 貼圖提示詞（直接複製貼上）

## 1. 角色設定圖
```
請幫我設計一個 LINE 貼圖用的原創角色，畫一張角色設定圖。
【角色描述】（之後每一張都會原封不動貼上這段）
角色：＿＿＿（例：戴粉色髮帶的小羊美甲師）
外型：＿＿＿（例：圓臉、大眼睛、短捲毛、奶茶色圍裙）
配色：＿＿＿（例：奶茶色為主，點綴粉紅與薄荷綠，最多 4 色）
畫風：Q 版、深色粗輪廓線、平塗上色、線條簡單
【畫面要求】
- 同一張圖畫出正面、側面、背面三個角度
- 透明背景 PNG
- 圖裡不要有任何文字、商標、店名
- 不要模仿任何現有的卡通角色或品牌角色
```

## 2. 每一張表情（只換【這一張】）
```
附件是我的角色設定圖，請畫同一個角色：臉型、髮型、服裝、配色都不能改。
【角色描述】
（貼上設定圖那一段，一字不改）
【這一張】
表情與動作：＿＿＿（例：雙手比讚、眨一隻眼睛）
要表達的意思：＿＿＿（例：收到！）
【畫面要求】
- 只畫這一個角色，半身為主，表情要大、動作要誇張
- 透明背景 PNG，構圖接近橫式的 370 比 320
- 角色四周留一點空白，不要貼到邊
- 圖裡不要寫任何字，字我自己加
```

## 3. 台詞發想
```
我是＿＿＿（美甲／美睫／做臉／美髮）工作室老闆，想做一組 8 張的 LINE 貼圖，
角色是＿＿＿。請列出 16 句我和客人在 LINE 最常用、又適合做成貼圖的短句（每句 6 個字以內），
避開任何優惠、宣傳、店名。我會從裡面挑 8 句。
```
