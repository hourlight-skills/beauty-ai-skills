# 化粧品廣告字眼檢查

化粧品不得宣稱醫療效能。新法取消了事前審查，但罰得重：廣告虛偽誇大罰 4 萬到 20 萬元，宣稱醫療效能罰 60 萬到 500 萬元。
**自保公式：描述「外觀與感受」，不承諾「治療與生理改變」。**

## 怎麼檢查
1. 請她貼上整段文字（貼文、價目表、官網、私訊都算；主管機關看的是文字、圖片、整體表現，一對一私訊也保守當廣告寫）
2. 逐句掃，標三級。**燈號是檢查的優先順序，法律上屬於哪一類要另外寫在「為什麼」那一欄**：
   - 🔴 高風險（例：治療、根治、消炎、消腫、殺菌、淡斑、消除黑色素、生髮、育毛、促進膠原蛋白增生、細胞再生、瘦身、燃脂、醫美級、藥用級）
     法律上分兩類，罰則不同：**涉及醫療效能**（《化粧品標示宣傳廣告涉及虛偽誇大或醫療效能認定準則》第 5 條、附件四，罰 60 萬到 500 萬元），**涉及虛偽或誇大**（同準則第 3 條、附件一，罰 4 萬到 20 萬元）。例如「殺菌」列在附件四、「瘦身、減肥」列在附件一；其他詞屬於哪一類，以準則附件原文為準，AI 不要自己歸類，寫「請對照準則附件或問衛生局」。
   - 🟠 誇大或承諾（例：保證、一定、100%、永久、終身、立即見效、幾天見效、第一名、最有效）
   - 🟡 要看上下文（例：修復、抗老、緊緻、排毒、改善、淡化）：單獨出現不一定違規，接在身體部位或療效後面就危險；「淡化細紋」這類說法部分化粧品類別通常可以用，仍要依整句與產品核對，而且加上時間或保證（「三天淡化」）就是承諾
   - 品牌自律（本技能包的規則，不是法條）：科學證明、研究證實、療癒、保證有效、一定會，一律改寫，就算她說有研究也不保留
   主管機關是看整句、整篇的意思綜合判斷，不是單一字出現就一定違規；詞的分類以準則附件原文為準，拿不準就標「請衛生局確認」。
3. 每一句給「改這樣寫」（照下表的方向），保留她原本的語氣
4. 最後列出：這篇有沒有提到醫療行為（打針、雷射、電波、注射或使用麻醉、麻藥）：**美容業不得執行醫療行為，也不能替診所做醫療廣告**

## 先分清楚：她在賣產品，還是在宣傳服務？
兩種看的規定不一樣，檢查結果要分開寫：
| 她在寫的是 | 主要看 | 重點 |
|---|---|---|
| **賣產品**（保養品、精油、洗髮精） | 化粧品衛生安全管理法、上面那份認定準則 | 產品不能宣稱醫療效能或虛偽誇大 |
| **宣傳服務**（做臉、按摩、美體、美睫、紋繡） | 醫療法第 84 條（非醫療機構不得做醫療廣告）、第 87 條（暗示或影射醫療業務也算醫療廣告）、第 17 條（店名不能像醫療機構） | 不能寫雷射、電波、脈衝光、注射（美白針、玻尿酸、肉毒）、麻醉、除疤、消脂溶脂、抗發炎、隆乳、「不打針不吃藥」；店名不能用「醫美中心」「理療中心」「醫學美容館」這類 |

宣傳服務時，有些字在服務廣告裡是可以的，**不要一律標紅**：新北市衛生局的宣導單把「淨白煥膚」「美體雕塑」「窈窕曲線」「纖體手技」「繡眉、紋眉、紋眼線」列在可以刊登；不可以的是「果酸換膚」「消脂、溶脂、減重」「促進淋巴循環」這類講生理改變或醫療處置的。拿不準就寫「請問縣市衛生局」。

## 常見改寫方向
| 別這樣寫 | 改這樣寫 |
|---|---|
| 治療痘痘、根治粉刺 | 幫助肌膚清爽、修飾粉刺外觀 |
| 淡斑、消除黑色素 | 幫助提亮、修飾暗沉 |
| 醫美級、藥用級 | 深層保養、沙龍級體驗 |
| 瘦身、燃脂 | 按摩放鬆、修飾線條 |
| 生髮、治療落髮 | 幫助頭皮清爽、維持髮絲外觀 |

## 衛生局最常抓的三類字眼（發佈前用手機搜尋功能找一遍）
臺北市衛生局 2025 年查到化粧品違規廣告 167 件、罰 1,051 萬元，前三名：
「促進細胞活動或膠原蛋白增生」46 件、「消炎、消腫」38 件、「生髮育毛」29 件。
違規廣告大多在網路上，最多的是店家自己的官網，臉書、IG 也榜上有名。

## 交出去的格式
```
【檢查結果】🔴 x 處　🟠 x 處　🟡 x 處
| 原句 | 等級 | 為什麼 | 改這樣寫 |
【改寫後全文】
【還要注意】（醫療行為、見證、前後對比照）
```

## 客人個資
文案裡有客人的姓名、電話、email、生日、認得出是誰的照片，先換成「一位客人」這類說法再檢查；改寫後的全文也一律不放客人姓名。見證只用客人自己說過的話，不自己編、不加人數或效果。

## 界線
這是發文前的自我檢查，不是法律意見。拿不準的，問縣市衛生局或律師。

## 小工具
不想每次叫 AI，也可以用本技能包的 `ad-wording-check.html`（在整包的 `tools` 資料夾，或技能包 GitHub 頁面的 `tools` 裡）：瀏覽器打開、貼上文字，就會標出需要再確認的用詞。沒標出來不代表一定沒問題，整句意思還是要自己看。
